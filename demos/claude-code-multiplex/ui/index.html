Hivekeep multiplex demo

connecting…

Three Claude Code agents run as Hivekeep Actors on a pool of only two workers. Each agent loops: send a short prompt, print the reply, then sit idle. Idle agents are suspended (their memory is snapshotted and their worker released) so another agent can be resumed onto that worker. This page polls every 2.5 seconds, so the rotation is visible as it happens.

Tasks

Each click hands a random canned task to a random agent. A task is queued while its agent waits for a worker, running while the agent holds one, and completed afterwards. The timing is simulated by this dashboard; the agents themselves keep their own loop.
