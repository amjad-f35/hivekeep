# hivekeep-demo-multiplex-ui

The dashboard for the multiplex demo (binary `multiplex-ui`). It shows
which worker hosts which agent Actor, tails the worker pod logs, and hands
out simulated tasks while Hivekeep suspends and resumes the agents. It is
configured with `HK_API_ENDPOINT` and, optionally, `HK_API_TOKEN`.
